# เอกสารย้อนหลัง

เอกสารในหมวดนี้เก็บไว้ตรวจที่มาของการตัดสินใจและหลักฐาน ณ commit/วันที่เดิม ไม่ใช่ข้อกำหนดหรือ backlog ปัจจุบัน. เริ่มทำงานจาก [สารบัญหลัก](../README.md)

| หมวด | เก็บอะไร | ใช้เมื่อใด |
| --- | --- | --- |
| [reports/](reports/) | ผลตรวจ R1–R6/R11 และประวัติ Git/TypeScript/การปรับเอกสาร | ต้องการตรวจว่า checkpoint เดิมทำอะไร ผ่านการตรวจใด และยังมีข้อจำกัดอะไร |
| [plans/](plans/) | แผนขั้นตอนของงานย่อยก่อนหน้า | ต้องการดูวิธีหรือเหตุผลของงานนั้น; แผน refactor ปัจจุบันอยู่ [ที่นี่](../FRONTEND_REFACTOR_PLAN_TH.md) |
| [pre-final-20261006/](pre-final-20261006/) | สเปก Analytics/Finance/Inbox และ Admin audit ก่อน Final 1.6 | ดูประวัติต้นแบบเท่านั้น; งานปัจจุบันยึด [Final 1.6](../MELEARN_V1_SCOPE.md) |

เอกสารเดิมอาจมีชื่อไฟล์ เส้นทาง source คำสั่ง และสถานะที่ล้าสมัย ให้ตรวจ implementation ปัจจุบันก่อนใช้. Git ยังเก็บประวัติก่อนย้ายและไฟล์ชี้ทางที่ถอนออกแล้ว
